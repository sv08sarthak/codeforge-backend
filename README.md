# CodeForge – Coding Platform Backend

## Tech Stack
- Node.js
- Express.js
- PostgreSQL

## Description
This project is a backend system for a coding platform where users can solve problems, submit code, and track progress.

## Features (Planned)
- Authentication (JWT)
- Problem APIs
- Submission system
- User dashboard

## API Endpoints

GET /api/users  
Returns list of users
